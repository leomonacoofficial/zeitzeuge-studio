Privacy Policy — ZEITZEUGE.AT Studio (Zeitzeuge_Agent)

Last updated: November 2026

Zeitzeuge_Agent respects user privacy and complies with all TikTok Developer Terms and GDPR regulations.

1. Data Accessed via TikTok API

When authorized via TikTok Login Kit (user.info.basic, video.upload, video.publish), the application accesses basic profile information (display name, avatar, open_id) and creator posting settings solely to display account status and upload documentary videos initiated by the creator.

2. Data Storage & Security

OAuth tokens are stored locally on the creator's encrypted workstation and are never shared with third parties.
